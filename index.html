Additive Neuron — Αριστοτελική Σύνθεση
Κάθε είσοδος πολλαπλασιάζεται με ένα βάρος και αθροίζεται. Απλό, γρήγορο, αλλά μπορεί να φτιάξει μόνο ευθείες γραμμές ως όρια απόφασης.
z = w₁·x₁ + w₂·x₂ + b // αθροίζει όλες τις εισόδους σταθμισμένα
ŷ = σ(z) // σ = sigmoid → έξοδος μεταξύ 0 και 1
Αριθμητικό Παράδειγμα (x₁=2, x₂=3, w₁=0.5, w₂=-0.3, b=0.1)
z = (0.5 × 2) + (−0.3 × 3) + 0.1
z = 1.0 − 0.9 + 0.1 = 0.2
ŷ = σ(0.2) = 0.55 → 55% πιθανότητα κλάση 1
Παράγωγος — Backpropagation (πώς μαθαίνει)
∂L/∂w₁ = (ŷ − y) · σ'(z) · x₁
Απλό, σταθερό gradient — εύκολο να εκπαιδευτεί
✅ Πλεονέκτημα
Γρήγορο, σταθερό, δεν εκρήγνυται
⚠ Μειονέκτημα
Μόνο ευθείες γραμμές — δεν βλέπει αναλογίες
Divisive Neuron — Πλατωνική Διαίρεση
Αντί να αθροίζει, διαιρεί — μετράει αναλογίες. Ο αριθμητής ενισχύει, ο παρονομαστής κανονικοποιεί. Φυσικά μη-γραμμικός.
num = w₁⁺·|x₁| + w₂⁺·|x₂| // αριθμητής — τι ενισχύεται
den = w₁⁻·|x₁| + w₂⁻·|x₂| + ε // παρονομαστής — κανονικοποίηση (ε=0.5 για σταθερότητα)
z = num / den // η διαίρεση δίνει φυσική μη-γραμμικότητα
Αριθμητικό Παράδειγμα (x₁=2, x₂=3, wP=[0.8,0.6], wN=[0.3,0.2])
num = 0.8×2 + 0.6×3 = 3.4
den = 0.3×2 + 0.2×3 + 0.5 = 1.7
z = 3.4 / 1.7 = 2.0
Παράγωγος — Analytical Backprop
∂z/∂wP₁ = |x₁| / den = 1.176
∂z/∂wN₁ = −num·|x₁| / den² = −2.353
Πιο πολύπλοκο αλλά analytically σωστό
✅ Πλεονέκτημα
Κανονικοποιεί, βλέπει αναλογίες, μη-γραμμικός
⚠ Μειονέκτημα
Αστάθεια αν den→0, αργότερη εκπαίδευση
Hybrid Neuron — Leibnizian Logos
Συνδυάζει και τα δύο: 50% additive + 50% divisive. Χρησιμοποιεί σύνθεση ΚΑΙ ανάλυση — όπως ο Leibniz έλεγε ότι ο νους κάνει.
z_add = w₁·x₁ + w₂·x₂ + b // additive branch
z_div = num / den // divisive branch
z = 0.5 · z_add + 0.5 · z_div // ισορροπία σύνθεσης και ανάλυσης
ŷ = σ(z)
Παράδειγμα (x₁=2, x₂=3)
z_add = 0.5×2 + (−0.3)×3 + 0.1 = 0.2
z_div = 3.4 / 1.7 = 2.0
z = 0.5×0.2 + 0.5×2.0 = 1.1
Backprop — και οι δύο κλάδοι μαθαίνουν
∂L/∂w₁ = 0.5 · (ŷ−y)·σ'·x₁
∂L/∂wP₁ = 0.5 · (ŷ−y)·σ'·|x₁|/den
Τα βάρη και των δύο κλάδων ενημερώνονται ταυτόχρονα
✅ Πλεονέκτημα
Ευέλικτο — παίρνει το καλύτερο και των δύο
⚠ Μειονέκτημα
Διπλάσιες παράμετροι, πιο αργό
Τι είναι το Epoch & Loss
EPOCH
1 epoch = το δίκτυο είδε όλα τα δεδομένα μία φορά και ενημέρωσε τα βάρη του.
Μετά από 100 epochs το δίκτυο έχει "ξαναδεί" τα δεδομένα 100 φορές.
LOSS (MSE)
Loss = Σ(ŷᵢ − yᵢ)² / n  — μέσο τετραγωνικό σφάλμα
Loss=0.25 σημαίνει μέση απόκλιση ~0.5 από τη σωστή απάντηση. Στόχος: Loss → 0.
ACCURACY
Ποσοστό σωστών προβλέψεων: ŷ > 0.5 → κλάση 1, αλλιώς κλάση 0.
Accuracy 90% = 9 στα 10 σωστά. Πιο κατανοητό από το Loss.
Η ΚΕΝΤΡΙΚΗ ΙΔΕΑ

Οι αρχαίοι φιλόσοφοι θεωρούσαν ότι η σκέψη είναι συνεχής μάζα και ο λόγος είναι το εργαλείο τομής — η γλώσσα διαιρεί το συνεχές σε κατηγορίες. Στο ML, ακριβώς αυτό κάνει ο νευρώνας: αθροίζει (σύνθεση) ή διαιρεί (ανάλυση) τον χώρο εισόδου.

∑
Αριστοτέλης — Σύνθεση
"Το όλον είναι περισσότερο από το άθροισμα των μερών"
ML ΑΝΤΙΣΤΟΙΧΙΑ
Additive Neuron: z = Σ wᵢxᵢ + b
Κάθε είσοδος συνεισφέρει σταθμισμένα. Η γνώση χτίζεται με συσσώρευση — αριστοτελική σύνθεση.
÷
Πλάτων — Διαίρεση (Diaeresis)
"Η γνώση προκύπτει από τη διαίρεση του γένους σε είδη" — Σοφιστής
ML ΑΝΤΙΣΤΟΙΧΙΑ
Divisive Neuron: z = Σw⁺xᵢ / Σw⁻xᵢ
Ο νευρώνας τέμνει. Μετράει αναλογίες, κανονικοποιεί, διακρίνει σήμα από θόρυβο. Πλατωνική Diaeresis σε μαθηματική μορφή.
⊕÷
Leibniz — Λόγος (Logos)
"Ο λόγος ενέχει και σύνθεση και ανάλυση"
ML ΑΝΤΙΣΤΟΙΧΙΑ
Hybrid: 0.5·Additive + 0.5·Divisive
Ο νους χρησιμοποιεί και τα δύο. Ακριβώς ο Hybrid νευρώνας — σύνθεση για να χτίσει, διαίρεση για να διακρίνει.
🧠
Εγκέφαλος — Divisive Normalization
"Carandini & Heeger (2012): ο οπτικός φλοιός χρησιμοποιεί διαίρεση"
ΒΙΟΛΟΓΙΚΟΣ ΤΥΠΟΣ
r = (σ · xⁿ) / (σ⁵⁰ + Σxⁿ)
Βιολογικά, ο εγκέφαλος κανονικοποιεί μέσω διαίρεσης — εξηγεί αντίληψη αντίθεσης και προσαρμογή στο φως.

ΣΥΜΠΕΡΑΣΜΑ

Τα νευρωνικά δίκτυα αντικατοπτρίζουν τη δομή της ανθρώπινης σκέψης. Η ερώτηση "μήπως η διαίρεση θα ήταν καλύτερη" οδήγησε στους Transformers — την αρχιτεκτονική που στηρίζει κάθε σύγχρονο LLM.

💡 Η ιδέα "divisive neuron" είναι η βάση των Attention Mechanisms. softmax(QKᵀ/√d)·V είναι ακριβώς divisive normalization. Ο Πλάτων θα το είχε αναγνωρίσει.
