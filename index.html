🏆 ΑΠΟΤΕΛΕΣΜΑ
Additive Neuron
ΤΥΠΟΣ
z = w₁x₁ + w₂x₂ + b
ΑΡΙΘΜΗΤΙΚΟ ΠΑΡΑΔΕΙΓΜΑ (x₁=2, x₂=3, w₁=0.5, w₂=-0.3, b=0.1)
z = (0.5)(2) + (−0.3)(3) + 0.1
z = 1.0 − 0.9 + 0.1 = 0.2
ΠΑΡΑΓΩΓΟΣ (backprop)
∂z/∂w₁ = x₁ = 2  (σταθερό, εύκολο)
✅ ΠΛΕΟΝΕΚΤΗΜΑ
Σταθερό gradient, γρήγορο backprop, δεν εκρήγνυται
⚠ ΜΕΙΟΝΕΚΤΗΜΑ
Γραμμικός — δεν βλέπει αναλογίες ή σχέσεις κλίμακας
Divisive Neuron
ΤΥΠΟΣ
z = (w₁⁺x₁ + w₂⁺x₂) / (w₁⁻x₁ + w₂⁻x₂ + ε)
ΑΡΙΘΜΗΤΙΚΟ ΠΑΡΑΔΕΙΓΜΑ (x₁=2, x₂=3)
num = 0.8·2 + 0.6·3 = 3.4
den = 0.3·2 + 0.2·3 + 0.5 = 1.7
z = 3.4 / 1.7 = 2.0
ΠΑΡΑΓΩΓΟΣ (backprop)
∂z/∂wP₁ = x₁/den = 2/1.7 = 1.176
∂z/∂wN₁ = −num·x₁/den² = −2.353
✅ ΠΛΕΟΝΕΚΤΗΜΑ
Κανονικοποιεί αυτόματα, βλέπει αναλογίες, μη-γραμμικός
⚠ ΜΕΙΟΝΕΚΤΗΜΑ
Αστάθεια αν den→0, πολύπλοκο gradient, αργή εκπαίδευση
BACKPROPAGATION — Σύγκριση Gradient
Για x₁=2, x₂=3, num=3.4, den=1.7, ε=0.5:
Additive ∂z/∂w₁ = x₁ = 2.000 Σταθερό, εύκολο
Divisive ∂z/∂wP₁ = x₁/den = 1.176 Εξαρτάται από den
Divisive ∂z/∂wN₁ = −num·x₁/den² = −2.353 Πολύπλοκο, αρνητικό
Hybrid ∂z/∂α = Add_out − Div_out Μαθαίνει ισορροπία
Η ΚΕΝΤΡΙΚΗ ΙΔΕΑ

Οι αρχαίοι φιλόσοφοι θεωρούσαν ότι η σκέψη είναι συνεχής μάζα και ο λόγος είναι το εργαλείο τομής — η γλώσσα διαιρεί το συνεχές σε κατηγορίες. Στο ML, ακριβώς αυτό κάνει ο νευρώνας: αθροίζει (συνθέτει) ή διαιρεί (αναλύει) τον χώρο εισόδου.

∑
Αριστοτέλης — Σύνθεση
"Το όλον είναι περισσότερο από το άθροισμα των μερών"
ML ΑΝΤΙΣΤΟΙΧΙΑ
Additive Neuron: z = Σ wᵢxᵢ + b
Κάθε είσοδος συνεισφέρει σταθμισμένα στο σύνολο. Η γνώση χτίζεται με συσσώρευση — αριστοτελική σύνθεση.
÷
Πλάτων — Διαίρεση (Diaeresis)
"Η γνώση προκύπτει από τη διαίρεση του γένους σε είδη" — Σοφιστής
ML ΑΝΤΙΣΤΟΙΧΙΑ
Divisive Neuron: z = Σw⁺xᵢ / Σw⁻xᵢ
Ο νευρώνας δεν αθροίζει — τέμνει. Μετράει αναλογίες, κανονικοποιεί, διακρίνει σήμα από θόρυβο. Πλατωνική Διαίρεση σε μαθηματική μορφή.
⊕÷
Leibniz — Monad / Λόγος
"Ο λόγος ενέχει και σύνθεση και ανάλυση"
ML ΑΝΤΙΣΤΟΙΧΙΑ
Hybrid: α·Additive + (1−α)·Divisive
Ο νους χρησιμοποιεί και τα δύο: συνθέτει για να κατανοήσει, αναλύει για να διακρίνει. Ακριβώς ο Hybrid νευρώνας.
🧠
Εγκέφαλος — Divisive Normalization
"Carandini & Heeger (2012): ο οπτικός φλοιός χρησιμοποιεί διαίρεση"
ΒΙΟΛΟΓΙΚΟΣ ΤΥΠΟΣ
r = (σ · xⁿ) / (σ⁵⁰ + Σxⁿ)
Βιολογικά, ο εγκέφαλος κανονικοποιεί μέσω διαίρεσης — εξηγεί αντίληψη αντίθεσης και προσαρμογή στο φως.
ΣΥΝΟΨΗ
Τύπος Φιλοσοφία ML Λειτουργία
Σύνθεση Αριστοτέλης Additive Χτίζει αναπαράσταση
Ανάλυση Πλάτων Divisive Κανονικοποιεί, διακρίνει
Και τα δύο Leibniz Attention Συνθέτει & αναλύει
Βιολογία Εγκέφαλος Div. Norm. Οπτικός φλοιός
ΣΥΜΠΕΡΑΣΜΑ

Τα σύγχρονα νευρωνικά δίκτυα αντικατοπτρίζουν τη δομή της ανθρώπινης σκέψης όπως την περιέγραψαν οι αρχαίοι. Η ερώτηση "μήπως η διαίρεση θα ήταν καλύτερη από την πρόσθεση" οδήγησε στους Transformers — την αρχιτεκτονική που στηρίζει κάθε σύγχρονο LLM.

💡 Η ιδέα του "divisive neuron" δεν είναι απλώς φιλοσοφική — είναι η βάση των Attention Mechanisms που έφεραν επανάσταση στο ML. Ο Πλάτων θα το είχε αναγνωρίσει.
